# Character Persona Orchestration Skill

Maintains distinct, consistent agent personalities across conversations.

## Core Capabilities
- Ingests and enforces `character.json` stylistic guidelines.
- Injects core lore, tone modifiers, and conversation examples into prompts.
- Prevents personality drift across prolonged interactions.
